# Gran Azul

Sitio de muestra con el sistema de diseño Gran Azul (repo `Gran-Azul-DS`).

**Solo para ver.** La home copia la estructura del sitio de referencia, en
su mismo orden (héroe con rastreo, tiendas verificadas, productos
destacados, propuesta de valor, pasos, servicios con estado, vendedores,
funcionalidades, ventajas, destinos, casillero, precios con calculadora y
oficinas), con contenido propio de Gran Azul. No se copian textos, marca,
fotos ni código del sitio de referencia. No es el sitio comercial final y
este paso puede cambiar en el futuro.

- Marca: `#0075A7`, cian `#13C1DF`, noche `#071D2F`, tipografía DM Sans.
- Tokens con prefijo `--ga-*` en `src/tokens.css`.
- Tema claro por defecto, tema oscuro disponible.
- La calculadora muestra un resultado **demo** (10 lb = 30 USD en aéreo)
  y dice explícitamente que no son tarifas reales.

```bash
npm install
npm run dev
npm run build
```
